Week 7 · October 5 – 9

Refactoring, Code Smells, Information Hiding & Clean Code

Monday: move the generation loop without changing behavior. Wednesday: review API boundaries, attack queries, and board restoration as preparation for king safety.

Milestones due: M3 — Monday, October 5 · M4 — Monday, October 12, both 11:59 PM

📋Topics covered

🌞 🌙
M4 preserves behavior. King-safety examples prepare for M5; they are not part of M4's required implementation.

Monday — refactoring and code smells

  • Distinguish refactoring from bug fixes and new features.
  • Investigate duplication, mixed responsibilities, and unnecessary type branches.
  • Extract the generation loop into MoveGenerator and delegate from Game.
  • Use tests to check behavior and the diff to check the structural change.

Wednesday — information hiding and clean code

  • Identify the decisions hidden behind an API and the limits of private fields.
  • Use names and comments that make decisions and effects clear.
  • Distinguish attacks from legal moves using pawns and a pinned rook.
  • Trace temporary board changes and restore accepted and rejected candidates.
