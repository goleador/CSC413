Week 10 · October 26 – 30

UML, Command & State

Monday: UML, the diagrams that describe a design, drawn from the engine you have built. Wednesday: two behavioral patterns, Command and State.

Opens: M5 — Monday, October 26 · Due: M5 — Monday, November 2, 11:59 PM

📋Topics covered

🌞 🌙
Schedule change. The Wednesday October 14 class was cancelled, so UML is this Monday and Command and State share Wednesday. Week 11 onward is unchanged.

Monday — UML

  • Midterm recap first: the class numbers, and a short review of the five questions that cost the most points.
  • Class diagrams: classes, interfaces, and the arrows between them.
  • Sequence diagrams: who calls whom, in what order.
  • Writing both as text in Mermaid, so they live in the repository next to the code.

Wednesday — Command and State

  • Command: a request turned into an object you can store, replay, and undo.
  • State: an object whose behavior changes with its state, without a growing switch.
