🚀Milestone M0 — repository & environment

M0 — due Monday, August 31 at 11:59 PM. Four things, about 30 minutes, and everything else this semester depends on them. Start early: you have class on Wednesday and Monday to ask about anything that breaks, but only if you have tried it by then.

  1. Install the tools. JDK 25 (Temurin), IntelliJ IDEA, and Git — follow the environment setup guide.
  2. Create your repository. A public GitHub repo named CSC413, exactly. Section 4 of the same guide walks you through seeding it from the course starter.
  3. Register it. Submit your repo URL on the course GitHub form so I know where to find your work.
  4. Prove it works. Run ./mvnw test in your repo. Three zeros and BUILD SUCCESS means you are ready.

Stuck? The setup guide has a troubleshooting section covering every error we have seen before. Bring anything it does not cover to class on Wednesday or Monday — copy the exact error text, and note which step you were on.
