Model, View, Controller

Monday: where each piece of code belongs, in any program, and then in the chess engine. Wednesday: how M7 works, where you generate views with AI.

Due: M5 — Monday, November 2, 11:59 PM · Opens: M6 — Monday, November 2

📋Topics covered

🌞 🌙
Both classes this week are on Zoom, at the usual time. The link is on Canvas.

Monday — Model, View, Controller

  • Three questions that sort any line of code into model, view, or controller, practiced on tic-tac-toe.
  • The dependency rule: the model knows nothing about the view or the controller.
  • Three tests of a good split: the model runs with no screen, a new view changes nothing else, a rule changes in one place.
  • Input from a loop or from events; the same shape in web and phone apps.
  • The chess engine as the model: BoardView, PlayerAction, and a new view added without changing Game or the controller.

Wednesday — Working with a coding agent

  • Chat or coding agent, and why an agent needs written instructions: what to do, what not to do, how to check, when to stop.
  • An agent adds a 2D Swing board live; checking it with the diff, a search, the tests, and by playing it.
  • Reviewing generated code, and comparing runs one change at a time.
  • How M7 works: groups of one to three, individual repositories, m7-submission.md.
