# Online Courses (MOOCs and Similar) Comparable to SFSU CSC 413, 2025–2026

Comparison baseline: CSC 413 "Software Development" — upper-division, 3-unit, Java, project-based. Topics: Java tooling (IntelliJ, Git/GitHub, Maven), OO design (encapsulation, inheritance, polymorphism, interfaces, composition), cohesion/coupling/SOLID, refactoring & code smells, UML, design patterns (Factory, Builder, Command, State, Strategy, Observer), MVC & layered architecture, debugging, JUnit, maintenance & technical debt. Semester-long console chess engine in 14 milestones.

## KQ1: For each candidate — provider, module/week structure, hours, projects, language, price/audit

### Takeaway
The closest single equivalent is the University of Alberta "Software Design and Architecture" Specialization on Coursera (4 courses × 4 weeks, Java, UML-heavy, design patterns + code smells + MVC, Android capstone). The UBC edX pair (based on CPSC 210) is the closest in spirit to a construction course in Java but its current availability on edX is uncertain. MIT's current 6.102 is free and rigorous but now in TypeScript; the Java version (6.005, Spring 2016) survives on OCW. Duke/UCSD Coursera specializations are intro-level Java programming, overlapping only partially.

### Cited Findings

**1. University of Alberta — "Software Design and Architecture" Specialization (Coursera)**
- URL: https://www.coursera.org/specializations/software-design-architecture
- 4 courses, each designed for 4 weeks (4 modules each); whole specialization ~16 weeks at ~10 hrs/week recommended; instructor Kenny Wong; 107,185 enrolled; rated 4.6/5 (4,050 reviews); level "Beginner" but "basic Java programming knowledge" is a stated prerequisite and assignments/quizzes require coding in Java — [Coursera specialization page](https://www.coursera.org/specializations/software-design-architecture)
- Course 1, **Object-Oriented Design** (~17 hrs): CRC analysis; OO principles (abstraction, encapsulation, decomposition, generalization); inheritance types; association/aggregation/composition; UML class diagrams and translation to Java code; modularity; cohesion vs. coupling tradeoffs — [Coursera](https://www.coursera.org/learn/object-oriented-design) (module detail via [specialization page](https://www.coursera.org/specializations/software-design-architecture))
- Course 2, **Design Patterns** (~15 hrs): design patterns for interactive applications; pattern selection/application; design principles including open-closed, dependency inversion, least knowledge; code smells and anti-patterns ("critique code by identifying and refactoring anti-patterns"); MVC — [Coursera](https://www.coursera.org/specializations/software-design-architecture)
- Course 3, **Software Architecture** (~10 hrs): architectural styles; layered and n-tier architectures; UML package, component, deployment, and activity diagrams; Architecture Tradeoff Analysis Method (ATAM) — [Coursera](https://www.coursera.org/specializations/software-design-architecture)
- Course 4, **Service-Oriented Architecture** (~10 hrs): SOA, WS*/SOAP/WSDL, REST, JSON/HTTP, microservices, Elasticsearch — [Coursera](https://www.coursera.org/specializations/software-design-architecture)
- Running project: a Java-based **Android app capstone that evolves through all four courses**, from single-user/local-storage to multi-user/remote-storage, built in Android Studio with provided setup tutorials — [Coursera](https://www.coursera.org/specializations/software-design-architecture)
- Pricing: enrollment via Coursera subscription / Coursera Plus; financial aid available; certificate requires payment (full free audit of the entire specialization not offered) — [Coursera](https://www.coursera.org/specializations/software-design-architecture)

**2. UBC — "Software Construction: Data Abstraction" (SoftConst1x) and "Software Construction: Object-Oriented Design" (SoftConst2x), edX, based on CPSC 210**
- Both are UBCx courses within the edX **Software Development MicroMasters** program, launched 2017 — [UBC CS news](https://www.cs.ubc.ca/news/2017/03/ubc-launches-edx-micromasters-program-software-development)
- Campus source course: CPSC 210 "Software Construction" (4 credits): design, development, and analysis of robust software components; software design, computational models, data structures, debugging, and testing — [UBC calendar](https://vancouver.calendar.ubc.ca/course-descriptions/courses/cpscv-210)
- **SoftConst1x (Data Abstraction)**: "powerful data abstraction and decomposition techniques to build large, complex programs" in **Java**; a 2017 listing gives **6 weeks at 8–10 hrs/week** — [scholarship-positions listing](https://scholarship-positions.com/blog-free-online-course-on-software-construction-data-abstraction/2017/08/12/) (page now redirects; figure from its indexed text), program context at [mastersportal](https://www.mastersportal.com/studies/176131/software-development-micromasters-program.html)
- **SoftConst2x (Object-Oriented Design)**: "digs deep into the principles of object-oriented design," introduces new abstraction techniques and **design patterns**; project "uses popular online services and APIs"; outcomes include reading/applying design patterns, implementing and **testing** OO designs, developing mobile applications; language Java; instructors Gail Murphy and Elisa Baniassad — [course README mirror](https://github.com/nasirxo/Courses-/blob/master/UBCx-Software-Construction-OOP-SoftConst2x/README.md); instructor listing at [MOOC List](https://www.mooc-list.com/instructor/elisa-baniassad)
- Availability as of Oct 2025 is **unclear**: the edX MicroMasters program URL (edx.org/masters/micromasters/ubcx-software-development) returns 404, and direct edX course-page URLs for both courses also 404; however, edX certificate records for UBCx courses exist with issue dates through **August 2025** — [edX certificate record](https://courses.edx.org/certificates/33501999a53c43ef8016f9a6967a389c). Treat as likely archived/retired or relocated; verify directly on edx.org before recommending.

**3. Duke — "Java Programming and Software Engineering Fundamentals" Specialization (Coursera)**
- URL: https://www.coursera.org/specializations/java-programming
- 5 courses, ~6 months at 10 hrs/week; beginner, no prerequisites; 4.6/5 (22,240 reviews); 343,253+ enrolled; uses the free BlueJ IDE — [Coursera](https://www.coursera.org/specializations/java-programming)
- Course list: (1) Programming Foundations with JavaScript, HTML and CSS (~33 h, not Java); (2) Java Programming: Solving Problems with Software (~18 h — Java fundamentals, debugging, "develop a set of test cases," CSV analysis); (3) Java Programming: Arrays, Lists, and Structured Data (~15 h — collections, maps, file I/O, encryption project); (4) **Java Programming: Principles of Software Design** (~13 h — multiple interacting classes, interfaces/Comparable, abstract classes, exception handling, performance; earthquake-data and predictive-text projects); (5) Capstone: Build a (Netflix-style) Recommendation System (~5 h) — [Coursera](https://www.coursera.org/specializations/java-programming)
- Pricing: free enrollment to view; certificate paid; financial aid; included in Coursera Plus — [Coursera](https://www.coursera.org/specializations/java-programming)

**4. UC San Diego (with Duke) — "Object Oriented Programming in Java" Specialization (Coursera)**
- URL: https://www.coursera.org/specializations/object-oriented-programming
- 4 courses, ~115 hours total, ~6 months at 10 hrs/week; 4.6/5 (15,099 reviews); 117,403+ enrolled — [Coursera](https://www.coursera.org/specializations/object-oriented-programming)
- Courses: (1) Java Programming: Solving Problems with Software (~18 h, Duke); (2) Java Programming: Arrays, Lists, and Structured Data (~15 h, Duke); (3) **Object Oriented Programming in Java** (~40 h, UCSD — OOP fundamentals, GUIs, event-driven programming, geospatial mapping/visualization, searching & sorting); (4) Data Structures and Performance (~42 h, UCSD — linked lists, trees, hashtables, Big-O, optimization) — [Coursera](https://www.coursera.org/specializations/object-oriented-programming)
- Projects: CSV analysis, encryption program, interactive geospatial map, text-data manager; **no game-like projects**; Coursera states "You cannot take this course for free" at enrollment (financial aid available) — [Coursera](https://www.coursera.org/specializations/object-oriented-programming)

**5. MIT 6.102 / 6.031 / 6.005 "Software Construction" (self-study)**
- Current public course site (Spring 2025): https://web.mit.edu/6.102/www/sp25/ — **TypeScript**, not Java ("Basic TypeScript" is the tool prerequisite) — [6.102 sp25 site](https://web.mit.edu/6.102/www/sp25/)
- 19 public readings: static checking; **testing**; **code review**; specifications; designing specifications; abstract data types; abstraction functions & rep invariants; **interfaces & subtyping**; functional programming; equality; recursive data types; grammars & parsing; **debugging**; concurrency; promises; mutual exclusion; callbacks & GUIs; message-passing & networking; little languages — [6.102 sp25 site](https://web.mit.edu/6.102/www/sp25/)
- Structure: 5 problem sets (PS0–PS4) each with alpha → code review → beta phases, plus a multi-iteration **"Star Battle" group game project**; readings and pset specs publicly accessible for self-study (grades/quizzes need MIT auth); free — [6.102 sp25 site](https://web.mit.edu/6.102/www/sp25/)
- Archived **Java** version on OCW: **6.005 Software Construction, Spring 2016** — "safe from bugs, easy to understand, ready for change"; specifications & invariants, testing, ADTs, **design patterns for OOP**, concurrency, functional programming; problem sets, programming assignments, exams with solutions; free under CC BY-NC-SA — [MIT OCW 6.005](https://ocw.mit.edu/courses/6-005-software-construction-spring-2016/)

**6. refactoring.guru / SourceMaking (refactoring & design patterns self-study)**

- These are references/short courses, not scheduled MOOCs — no weekly structure, no graded projects, no certificate.

### Inferences
- The UAlberta specialization is the only Coursera/edX offering that, like CSC 413, treats design (not programming) as the subject: UML, cohesion/coupling, patterns, code smells, MVC, layered architecture, all with Java assignments and a multi-course evolving project.
- Duke's specialization overlaps mostly with a CS1/CS2 prerequisite chain; only Course 4 ("Principles of Software Design") touches CSC 413 territory (interfaces, abstract classes), and it never reaches patterns, UML, SOLID, or refactoring as named topics.
- MIT 6.005 (OCW) was taught in Java (the 6.00x "Software Construction" line moved to TypeScript only with 6.102 in 2022); the OCW page itself does not name the language, so treat "Java" as well-established background knowledge rather than page-cited.
- UBC's pair, if still enrollable, is the best structural match for the first half of CSC 413 (robust construction, testing, OO design, patterns in Java, derived from a real university course), but the apparent retirement of the MicroMasters makes it unreliable to assign in 2025–26.

## KQ2: Which CSC 413 topics does each cover, and which are missing?

### Takeaway
No single MOOC covers the full CSC 413 list. UAlberta covers OO design + UML + patterns + code smells + MVC/layered architecture but not Git/Maven/IntelliJ tooling, JUnit practice depth, or technical debt as a named unit; MIT covers testing, specs, code review, and debugging rigor but (currently) not in Java and with little UML; refactoring.guru covers exactly the refactoring/smells/patterns/SOLID slice and nothing else; tooling (Git/GitHub, Maven, IntelliJ) is the topic most consistently absent everywhere.

### Cited Findings
- UAlberta: covers encapsulation/inheritance/composition, cohesion & coupling, UML class/package/component/deployment/activity diagrams, design patterns, open-closed & dependency-inversion principles (SOLID subset), code smells/anti-pattern refactoring, MVC, layered/n-tier architecture — [Coursera](https://www.coursera.org/specializations/software-design-architecture). Not listed anywhere on the page: Git, Maven, IntelliJ, JUnit by name, technical debt as a unit.
- Duke: covers Java fundamentals, debugging ("debugging using scientific method"), interfaces (Comparable), abstract classes, exceptions, writing test cases; no mention of UML, SOLID, design patterns by name, refactoring, Git/Maven — [Coursera](https://www.coursera.org/specializations/java-programming)
- UCSD: covers OOP fundamentals, event-driven GUIs, data structures/Big-O; no UML, SOLID, patterns, refactoring on the page — [Coursera](https://www.coursera.org/specializations/object-oriented-programming)
- MIT 6.102: covers testing, code review, specifications, ADTs, interfaces & subtyping, debugging, concurrency; in TypeScript — [6.102 sp25](https://web.mit.edu/6.102/www/sp25/); 6.005 (Java, archived) adds "design patterns for object-oriented programming" — [OCW](https://ocw.mit.edu/courses/6-005-software-construction-spring-2016/)
- UBC SoftConst2x: design patterns, implementing & testing OO designs, Java — [README mirror](https://github.com/nasirxo/Courses-/blob/master/UBCx-Software-Construction-OOP-SoftConst2x/README.md); CPSC 210 source course includes debugging and testing — [UBC calendar](https://vancouver.calendar.ubc.ca/course-descriptions/courses/cpscv-210)
- refactoring.guru/SourceMaking: code smells, refactoring techniques, 22 GoF patterns, SOLID principles, multi-language incl. Java — [refactoring.guru](https://refactoring.guru/refactoring/course); [sourcemaking](https://sourcemaking.com/store)
- Udemy (Coffee Powered Crew, Holczer Balazs, etc.): SOLID + GoF patterns in Java with hands-on exercises — [listing](https://www2.ctgoodjobs.hk/Learning/1420151509/udemy/java-design-patterns-solid-design-principles)

## KQ3: Does anything use a game/chess-like running project?

### Takeaway
Nothing found replicates CSC 413's semester-long chess engine. The nearest analogues are MIT 6.102's multi-iteration "Star Battle" puzzle-game group project (TypeScript, campus-oriented) and UAlberta's four-course evolving Android app (not a game).

### Cited Findings
- MIT 6.102 Spring 2025 runs a group project building the "Star Battle" puzzle game across multiple iterations — [6.102 sp25 site](https://web.mit.edu/6.102/www/sp25/)
- UAlberta capstone is an Android application evolving from single-user/local-data to multi-user/remote-data across all 4 courses — a sustained cumulative project, but an app, not a game — [Coursera](https://www.coursera.org/specializations/software-design-architecture)
- Duke capstone is a movie recommendation engine; UCSD projects are mapping/text apps — no games — [Duke spec](https://www.coursera.org/specializations/java-programming); [UCSD spec](https://www.coursera.org/specializations/object-oriented-programming)
- UBC SoftConst2x project "uses popular online services and APIs" (not a game) — [README mirror](https://github.com/nasirxo/Courses-/blob/master/UBCx-Software-Construction-OOP-SoftConst2x/README.md)

### Inferences
- A chess-anchored, milestone-driven structure appears to be a distinctive feature of CSC 413 relative to every mainstream MOOC equivalent surveyed; MOOC projects are either per-course mini-projects or a single evolving app.

### Gaps
- Udemy hosts assorted "build a chess game in Java" hobby courses, but none were verified in this research pass for quality or design-course content, so none are reported here.
