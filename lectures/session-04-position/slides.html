Step 3 — the bounds check

/** Files and ranks both run 0..7. */
public static final int BOARD_SIZE = 8;

/** True when these raw coordinates name a real square. */
public static boolean isOnBoard(int file, int rank) {
    return file >= 0 && file < BOARD_SIZE && rank >= 0 && rank < BOARD_SIZE;
}

static: it must answer before any Position exists — the constructor is about to call it.

Step 4 — the compact constructor

public Position {
    if (!isOnBoard(file, rank)) {
        throw new IllegalArgumentException(
                "Position off board: file=" + file + ", rank=" + rank);
    }
}

From here on, no other class ever validates a position. (rejectsOffBoard stays red — it also exercises parse. Your parse flips it.)

Step 5 — toString

@Override
public String toString() {
    return "" + (char) ('a' + file) + (char) ('1' + rank);
}
  • File 4 → 'a' + 4 → 'e'; rank 1 → '2'. So "e2".
  • Drop the leading "" and it prints 151 — int arithmetic, 101 + 50
Write it wrong first, run it, get 151, ask what happened. Ten seconds; inoculates them against a symptom they'd chase alone.
