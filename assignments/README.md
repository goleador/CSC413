# Assignments

Milestone handouts for the chess project (M0–M13), plus any standalone
exercises.

Each assignment directory should contain:

- `handout.md` — what students build, the acceptance criteria, and how it is
  submitted.
- `rubric.md` — the grading breakdown.
- `starter/` — any scaffolding code, if the milestone needs it.

Milestones are cumulative: each builds on the previous week's code rather than
starting fresh. The reference implementation lives in the separate
`CSC413-chess-reference` repository; students receive generated scaffolds from
`CSC413-chess-starter`, one tag per milestone.

Handouts are authored here and copied into the starter repo as
`docs/milestones/mNN.md` at release time, so students read the assignment next to
the failing tests it describes.

Acceptance criteria should lean on the test suite wherever possible — "your
perft(4) returns 197,281" is a far better criterion than a prose description of
correct move generation.
